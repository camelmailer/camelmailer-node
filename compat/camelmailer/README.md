# camelmailer

This package has moved to **[`@camelmailer/sdk`](https://www.npmjs.com/package/@camelmailer/sdk)**.

```bash
npm install @camelmailer/sdk
```

```ts
import { CamelMailer } from '@camelmailer/sdk';
```

This package stays published so that the name belongs to the Camelmailer
project and so code written against the old name keeps working: it re-exports
`@camelmailer/sdk` unchanged. It receives no updates of its own.

Source, issues and documentation live at
[camelmailer/camelmailer-node](https://github.com/camelmailer/camelmailer-node)
and [camelmailer.com/docs](https://camelmailer.com/docs).
